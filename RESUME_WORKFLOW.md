# Résumé workflow

The public portfolio offers one current professional résumé instead of multiple role-specific variants.

- The Contact section opens a pre-addressed email requesting Aryan's latest résumé. This prevents stale documents from remaining public.
- If a public download is needed later, place the PDF at `public/resumes/aryan-tripathi-resume.pdf` and replace the file at that same path whenever the résumé changes.
- Keep only one résumé action in the interface.
