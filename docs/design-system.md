# Design System

## Principles

1. Evidence is the visual hierarchy: status, source and limitation remain close to every claim.
2. Awakening without imitation: the experience borrows the energy of elastic animation, not protected characters, costumes, symbols or franchise artwork.
3. Depth is progressive: semantic HTML works first; canvas, parallax and 3D transforms enhance capable devices.
4. Motion directs attention and never blocks navigation.
5. Aryan appears as an identity-preserving animated cutout, not a raw photograph or a generic character.

## Visual language

The interface is a luminous white engineering world built from warm paper, heavy carbon outlines, imperfect geometry, crimson energy rings and tactile editorial type. It feels elastic and cinematic while remaining professional. Project cards behave like physical system panels, and the Digital Twin becomes the controlled black-ink counterpoint.

## Tokens

| Role | Value |

| Luminous white | `#fffef9` |

| Bright crimson | `#e14a3e` |
| Muted graphite | `#716d66` |

Crimson identifies energy, evidence and primary action. Black supplies structure and contrast; white carries the atmosphere.

## Typography

- Display and interface: Geist Sans
- Technical labels and coordinates: Geist Mono
- Narrative emphasis: system Georgia
- Display text uses compact tracking; body text stays between 1.55 and 1.8 line-height.

## Spacing

The base rhythm is 4px. Common steps are 8, 12, 16, 24, 32, 48, 64, 96 and 144px. Section padding uses responsive `clamp()` values.

## Motion system

- Canvas field: drifting cloud puffs, elastic ink route and sun-ring pulse
- Character: 4K-class transparent cutout with breathing, floating and pointer-relative perspective
- Character depth: independent ring, ribbon, burst, shadow and identity-label layers
- Project systems: spring lift, irregular radii and ink-shadow response
- Compass: hand-drawn directional wobble
- Mobile and reduced-motion: all continuous effects stop or become still
- Modes: Full, Balanced and Minimal; initial mode derives from reduced-motion and CPU core count

## Component inventory

- Fixed header and conventional mobile menu
- Awakening canvas with semantic section fallback
- Animated identity-preserving character stage
- Primary and quiet actions
- Section coordinate labels
- Project systems with native `<details>` case studies
- Architecture route
- Private-system audit card
- Experience log
- Evidence-linked skill loadout
- Searchable credential vault
- Horizontal timeline
- Deterministic Digital Twin console
- Trust and evidence layer
- Professional contact panel with email, phone, LinkedIn and GitHub

## Responsive behavior

- Desktop: cinematic 2.5D character composition and 12-column project world
- Tablet: two-column project system and compact header
- Mobile: conventional full-screen menu, single-column content and stopped 3D transform
- Important content is never available only through hover, canvas or color.

## Accessibility

- Semantic headings, sections, articles, lists, links and native disclosure controls
- Skip link, visible focus, keyboard-operable menu and assistant
- Live region for Digital Twin responses
- Meaningful character alternative text
- Reduced-motion and manual Minimal mode
- No canvas-dependent information

## States

- Loading: essential HTML server-renders; canvas begins only after hydration
- Error: canvas absence does not affect content; missing certificate PDFs display a text state
- Empty: certificate search shows an explicit no-results message
- Orvion: unavailable evidence is an intentional audit-pending state, not a fake feature card
