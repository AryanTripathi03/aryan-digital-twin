# Contributing

This is a personal portfolio. Changes should preserve factual accuracy, confidentiality, accessibility and the evidence trail.

## Content change checklist

1. Classify the source as public code, public document, user-confirmed context, requires confirmation or excluded.
2. Update the matching inventory and `FACT_CHECK_REPORT.md`.
3. Avoid company/customer/student/loan/invoice data and credentials.
4. Add limitations next to capabilities.
5. Keep Digital Twin knowledge synchronized with visible portfolio content.

## Engineering checklist

- Preserve semantic HTML and mobile navigation.
- Preserve Minimal and reduced-motion behavior.
- Do not add large animation/3D dependencies without a measured need.
- Do not create client-only admin authentication.
- Run lint, build and tests.
- Review public assets and generated bundles for confidential data.
