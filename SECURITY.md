# Security Policy

## Reporting

Report portfolio vulnerabilities through Aryan Tripathi's verified LinkedIn profile. Do not include sensitive data in a public GitHub issue.

## Scope

The portfolio has no account system, message storage, upload route or public admin. Security findings in linked project repositories should be reported to the repository owner and not tested against a live deployment without permission.

## Data policy

Never commit credentials, private company files, customer information, student records, lending data, invoice details or raw industrial workbooks. See `docs/security-model.md`.
